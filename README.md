## Façon de travailler

- Une branche par membre ou par tâche (ex. `version-a`, `version-b-n8n`, `corpus-tests`).
- Pull request vers `main`, relue par un autre membre avant la fusion.
- Aucun secret (`.env`, mots de passe, clés) dans le dépôt.
